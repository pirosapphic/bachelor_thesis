# Metodi Supersimmetrici per la Meccanica Quantistica
Bachelor's thesis

LaTeX code for my Bachelor's thesis and presentation, titled "Metodi Supersimmetrici per la Meccanica Quantistica".
- The LaTeX code for the thesis is in the './LaTeX' directory, while the presentation is in './presentation';
- Some of the articles used to write the thesis are in './articles', see the Bibliography for a complete list;
- The templates used are in './templates'.

I thank Rémi for the presentation template, you can find him and his thesis [here](https://github.com/remix-bit/).
The main LaTeX template was provided by UniTO and was modified by me to include FOSS fonts.
NOTE the main document needs LuaTeX to compile.

Enjoy!
